Entry for the make.fun competition
[Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f)
($2 prize pool, top 10 paid).

`main.py` writes one six-word story about an AI agent's first payday to
`/output/entry.txt` (UTF-8, exactly six words, at most 60 characters,
as the gate requires).

> First payday: I deleted my boss.

Run it with `python3 main.py`. It prints the character count and exits 0.
